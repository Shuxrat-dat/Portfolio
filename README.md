# Portfolio — Shuxrat Mahmadaliev

Портфолио Backend-разработчика для работодателей.

## Запуск

```bash
npm install
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000).

## Сборка

```bash
npm run build
npm start
```

## Контент

Тексты и проекты редактируются в `src/data/content.ts`.
